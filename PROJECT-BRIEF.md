# WHITE ROOM — Project Brief

## Vision

WHITE ROOM is a macOS desktop environment designed around self-directed learning, focused work, and RPG-inspired progression.

Its purpose is to make learning more engaging by combining a distraction-controlled workspace with personalized curricula and a rewarding progression system.

## Core Experience

A user should be able to:

1. Enter WHITE ROOM.
2. Choose a focus mode.
3. Select an existing learning path or create their own.
4. Launch the applications and resources they need.
5. Complete lessons, exercises, assessments, and projects.
6. Earn XP and Focus Credits.
7. Improve subject mastery and unlock achievements.
8. Purchase cosmetics using earned Focus Credits.
9. Review their progress.

## Product Systems

### Desktop Environment
A fullscreen macOS workspace with:
- Dashboard.
- Application launcher.
- Embedded tools.
- External application integrations.
- Standard and Strict focus modes.

### Learning Environment
A flexible curriculum engine supporting:
- Academic subjects.
- Independent learning.
- User-created courses.
- Curriculum packs.
- Lessons and exercises.
- Assessments.
- Practical projects.

### RPG Progression
A character progression system featuring:
- XP.
- Levels.
- Subject-specific skill trees.
- Achievements.
- Mastery tracking.

### Economy
A cosmetic reward economy featuring:
- Focus Credits.
- Cosmetic inventory.
- Cosmetic shop.
- Unlockable themes and customization.

## Product Constraints

- macOS first.
- Local-first.
- Offline-capable.
- No mandatory accounts.
- No mandatory subscriptions.
- No productivity surveillance.
- No punitive streak systems.
- Emergency exit always available.
- Cosmetics must not affect educational progression.

## Visual Direction

Clinical, minimalist, monochromatic.

WHITE ROOM should resemble a futuristic research facility rather than a conventional productivity application.

The RPG elements should complement the scientific aesthetic.

## Long-Term Vision

WHITE ROOM should eventually support:
- Community curriculum packs.
- Extensible application integrations.
- Custom learning paths.
- Optional AI-assisted curriculum creation.
- Advanced analytics.
- More sophisticated desktop customization.
- Additional operating systems.

The long-term goal is to create a flexible learning environment that users can make their own.
